# ADR-001 — Composable taxonomy

Status: ACCEPTED IN BOOTSTRAP HANDOFF

Recorded: 2026-10-07. This records an existing decision, not a newly claimed design review.

## Context

A single transformation can preserve information while collapsing structure and misplacing components.

## Decision

A lineage relationship carries multiple taxonomy events.

## Alternative and rationale

One mutually exclusive transformation status.

It would erase independently meaningful observations.

## Consequences

Tests and UI must support event combinations and component-level attribution.
