# ADR-003 — Canonical semantic model

Status: ACCEPTED IN BOOTSTRAP HANDOFF

Recorded: 2026-10-07. This records an existing decision, not a newly claimed design review.

## Context

Many artifact families must be comparable without making one the truth.

## Decision

Map each supported format into a shared semantic representation.

## Alternative and rationale

Pairwise format-to-format comparison logic.

Pairwise logic becomes difficult to scale as formats increase.

## Consequences

Version the model, preserve original evidence, and avoid interpreting canonical fields as standards authority.
